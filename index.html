Home workout plan

5 strength days, 3 runs. Goal: lose fat and build muscle.

How to add weight and reps over time
  • Add 1 rep per set each week.
  • At 12 reps (8 for lunges), add a 4th set.
  • Then use a harder version: incline, then knee, then full push-up.
  • For holds, add 5 sec each week.
  • The last 2 reps should feel hard. Do not push to failure.
  • Stop if you feel sharp pain.
