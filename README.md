# workout-plan

A simple web page to follow a 5-day home workout plan. It has 3 runs each week. The goal is fat loss and muscle gain. No equipment is needed.

**Live page:** https://yash19pro.github.io/workout-plan/


## Features

- Day tabs for Monday to Sunday. A dot marks the run days.
- Each session has a warm-up, a workout, a run (on run days), and a cool-down.
- Set the number of sets for each exercise (1 to 8, default 3).
- Pick a difficulty for each exercise: Easy, Easy-medium, Medium, Medium-hard, or Hard. Reps change to match.
- Tap "Set all exercises to…" to change the whole day at once.
- Tap a set to mark it done. A progress bar shows how much of the day you finished.
- Short "How to do it" steps for every exercise and stretch.
- Light and dark mode.

## Weekly plan

| Day | Session | Run |
|-----|---------|-----|
| Mon | Core | – |
| Tue | Chest + Shoulders | 5 km |
| Wed | Legs + Arms | – |
| Thu | Back | 5 km |
| Fri | Full Body | – |
| Sat | Run only | 5 km |
| Sun | Rest | – |

Each strength day has a stretch of 5 min or less before and after.

## Difficulty levels

Easy uses the starting reps. The other levels multiply them.

| Level | Reps |
|-------|------|
| Easy | ×1 |
| Easy-medium | ×1.25 |
| Medium | ×1.5 |
| Medium-hard | ×1.75 |
| Hard | ×2 |

Timed holds round to the nearest 5 seconds. When you reach Hard, use a harder version of the move. For example, change a knee push-up to a full push-up.
